# Ubiquitous Language Glossary

> Single source of truth for domain terminology in this repository.
> Code, specs, tickets, and tests MUST use these exact terms and reject listed synonyms.

---

# 1. Document & Generation Domain

## Admission Queue

- **Definition:** A bounded FIFO concurrency gate that regulates access to CPU- and memory-intensive rendering workers (Chromium browser contexts or presentation generation jobs). Enforces maximum concurrent execution slots and a strict timeout for waiting jobs.
- **What It Is NOT:** Not a distributed job broker (like Celery or BullMQ); an `Admission Queue` is an in-process, transient admission gate that rejects overflow with HTTP 503 or 429.
- **Rejected Synonyms (Do Not Use):** `Render Pool`, `Work Queue`, `Task Worker`, `Job Buffer`
- **Canonical Type / Schema:** `src/queue/generation-queue.ts :: GenerationQueue`
- **Lifecycle / Invariants:** `Enqueued -> Admitted -> Completed | Cancelled | TimedOut`. Client disconnects immediately trigger cancellation of waiting jobs.

---

## Authored Template

- **Definition:** A pre-existing, human-designed Microsoft PowerPoint (`.pptx`) file stored in the server's `templates/` directory that provides baseline layouts, themes, styling, and shape hierarchies for report generation.
- **What It Is NOT:** Not a code-generated slide structure or PptxGenJS script; it is a physical binary OpenXML archive authored in PowerPoint desktop.
- **Rejected Synonyms (Do Not Use):** `Theme`, `Preset`, `Master Deck`, `Base File`
- **Canonical Type / Schema:** `src/reports/template.ts :: templateFile`
- **Lifecycle / Invariants:** Validated at application startup (`validate()`). Must contain valid `[Content_Types].xml` and `ppt/presentation.xml`. Must never be modified directly on disk.

---

## Export Format

- **Definition:** The binary target container format generated by the service and returned in the HTTP response (`pdf` or `pptx`).
- **What It Is NOT:** Not a MIME content-type string directly; it is the domain enum selecting the pipeline, queue, and content headers.
- **Rejected Synonyms (Do Not Use):** `FileType`, `DocumentType`, `MimeFormat`, `Extension`
- **Canonical Type / Schema:** `src/http/constants.ts :: ExportFormat`
- **Lifecycle / Invariants:** Strictly `'pdf' | 'pptx'`.

---

## Navigation Boundary

- **Definition:** The security sandbox that constrains headless Chromium to only request and navigate within authorized origin domains (`WEBAPP_BASE_URL` or an explicit server-configured `externalOrigin`).
- **What It Is NOT:** Not an authentication or CORS policy; it is an active CDP network interceptor and Playwright route handler blocking cross-origin hops and server redirect escapes.
- **Rejected Synonyms (Do Not Use):** `CORS Filter`, `Origin Guard`, `Domain Firewall`
- **Canonical Type / Schema:** `src/services/pdf/navigation-boundary.ts :: navigationBoundary`
- **Lifecycle / Invariants:** Any cross-origin navigation attempt immediately aborts rendering with `502 NAVIGATION_BLOCKED`.

---

## Object Alias

- **Definition:** The camelCase developer identifier defined as a key in `templateSettings` (e.g. `x2Tab1`, `x3Title`) that maps code calls to an underlying shape, table, or chart.
- **What It Is NOT:** Not the name authored inside Microsoft PowerPoint; an `Object Alias` is the internal TypeScript identifier used on `TemplateDeck` handles.
- **Rejected Synonyms (Do Not Use):** `Shape Key`, `Property Name`, `Field Name`, `Handle Name`
- **Canonical Type / Schema:** `src/services/jszip/template-settings.ts :: TemplateSettings`

---

## Object Template

- **Definition:** A PowerPoint presentation generation approach that reads an Authored Template and performs direct OpenXML DOM manipulations on specific shapes identified by Selection Pane Name (e.g., resizing tables, populating chart Excel workbooks, modifying run text).
- **What It Is NOT:** Not `Placeholder Template` (which does regex string replacement); an `Object Template` manipulates XML nodes and preserves native chart editability.
- **Rejected Synonyms (Do Not Use):** `DOM Presentation`, `Shape Template`, `Interactive Template`
- **Canonical Type / Schema:** `src/services/jszip/presentation-service.ts :: PresentationService`

---

## Placeholder Template

- **Definition:** A PowerPoint presentation generation approach that scans an Authored Template for `{{key}}` text tokens across slides and speaker notes, replacing them with dynamic scalar text while preserving character formatting.
- **What It Is NOT:** Not an `Object Template`; a `Placeholder Template` does not bind to tables, charts, or named shapes, and cannot alter document structure.
- **Rejected Synonyms (Do Not Use):** `Token Replacement`, `String Interpolator`, `Simple Template`
- **Canonical Type / Schema:** `src/services/jszip/power-point-template-service.ts :: PowerPointTemplateService`

---

## Programmatic Layout

- **Definition:** A presentation structure constructed entirely through procedural code using PptxGenJS without loading an authored `.pptx` template file.
- **What It Is NOT:** Not a `Template`; there is no pre-existing `.pptx` file on disk. Layout, positioning, and shapes are hardcoded in TypeScript.
- **Rejected Synonyms (Do Not Use):** `Template` (in PptxGenJS contexts), `Code Deck`, `Dynamic Presentation`
- **Canonical Type / Schema:** `src/services/pptxgenjs/power-point-generation-service.ts :: PowerPointGenerationService`

---

## Report Definition

- **Definition:** The declarative specification of an HTTP endpoint producing a downloadable document, declaring request validation schemas, input mappers, queue assignments, and factory services.
- **What It Is NOT:** Not the rendered binary file itself; it is the route configuration object (`PdfReport` or `PptxReport`).
- **Rejected Synonyms (Do Not Use):** `Route Config`, `Endpoint Definition`, `Job Spec`
- **Canonical Type / Schema:** `src/reports/pdf.ts :: PdfReport` & `src/reports/pptx.ts :: PptxReport`

---

## Selection Pane Name

- **Definition:** The exact string assigned to a shape, table, graphic frame, or image in Microsoft PowerPoint's Selection Pane (e.g. `'X2_TAB1'`, `'CHART_REVENUE'`), serialized into `cNvPr[name]`.
- **What It Is NOT:** Not an `Object Alias` (which is the camelCase code key); this is the authored OpenXML name inside the template.
- **Rejected Synonyms (Do Not Use):** `Shape Name`, `Element Name`, `Node Name`, `PowerPoint ID`
- **Canonical Type / Schema:** `src/pptx/jszip/objects.ts :: NamedObject`
- **Lifecycle / Invariants:** Must be unique within a single slide. When duplicated, handles resolve relative to their owning slide.

---

## Slide

- **Definition:** A single presentation screen within an OpenXML PowerPoint package (`ppt/slides/slide{N}.xml`), containing shapes, tables, charts, and layout relations.
- **What It Is NOT:** Never call a slide a `Page`. A `Page` is strictly a PDF or web document surface.
- **Rejected Synonyms (Do Not Use):** `Page`, `Screen`, `Sheet`
- **Canonical Type / Schema:** `src/pptx/jszip/slides/list.ts :: listSlides`
- **Lifecycle / Invariants:** 1-based indexing in presentations. Modifying slide count (via duplication or deletion) mutates presentation relationships (`presentation.xml.rels`) and slide ID lists (`p:sldIdLst`).

---

## Slide Handle

- **Definition:** A scoped programming interface bound to a specific slide within an active `TemplateDeck`, exposing table, chart, text, and image handles exclusively located on that slide.
- **What It Is NOT:** Not a global deck interface; accessing aliases belonging to other slides from a `SlideHandle` is an error.
- **Rejected Synonyms (Do Not Use):** `Slide View`, `Page Handle`, `Slide Context`
- **Canonical Type / Schema:** `src/services/jszip/template-settings.ts :: SlideHandle`

---

## Template Deck

- **Definition:** An active, mutable in-memory session of an Authored Template archive, binding named objects and slides to typed manipulation handles for a single generation request.
- **What It Is NOT:** Not the raw disk file or the `TemplateSource`; a `TemplateDeck` is transient and request-scoped.
- **Rejected Synonyms (Do Not Use):** `Presentation Instance`, `Deck Session`, `Workbook`
- **Canonical Type / Schema:** `src/services/jszip/template-settings.ts :: TemplateDeck`
- **Lifecycle / Invariants:** `Opened -> Populated -> Serialized (toBuffer)`. Must serialize modified slide XML documents and flush pending chart workbooks before export.

---

## Template State

- **Definition:** The operational lifecycle status of presentation templates verified by the service during startup readiness checks.
- **What It Is NOT:** Not request state; it reflects application-level health for readiness probes.
- **Rejected Synonyms (Do Not Use):** `Template Status`, `Validation Status`, `Readiness Phase`
- **Canonical Type / Schema:** `src/observability/constants.ts :: TemplateState`
- **Lifecycle / Invariants:** `validating -> ready | failed`. A state of `failed` causes `/ready` to return 503.

---

## Web Page PDF

- **Definition:** A printable document generated by navigating a headless Chromium browser instance to an authorized internal web application route and executing CSS print media emulation.
- **What It Is NOT:** Not a programmatic PDF built with PDFKit or jsPDF; it is an HTML/CSS webpage printed via Chrome DevTools Protocol.
- **Rejected Synonyms (Do Not Use):** `HTML PDF`, `Puppeteer PDF`, `Browser Export`
- **Canonical Type / Schema:** `src/services/pdf/web-page-pdf.ts :: WebPagePdfService`

# 2. Upstream Data Domain

## Customer Data

- **Definition:** Profile and identity metadata for an organization retrieved from the upstream Data API, including industrial classification and primary contact details.
- **What It Is NOT:** Not authentication or billing account records; purely analytical profile data for reports.
- **Rejected Synonyms (Do Not Use):** `Client Info`, `Account Profile`, `Tenant Details`
- **Canonical Type / Schema:** `src/data-api/customer-data-schema.ts :: customerDataSchema`

---

## Report Data

- **Definition:** Multi-series tabular metrics, categorical series, and data points fetched from the Data API for a specific report identifier, calendar year, and localized language.
- **What It Is NOT:** Not presentation-ready formatted data; raw API values requiring formatting and layout projection.
- **Rejected Synonyms (Do Not Use):** `Report Payload`, `Raw Metrics`, `Analytics Payload`
- **Canonical Type / Schema:** `src/data-api/report-data-schema.ts :: reportDataSchema`

---

## Report Summary

- **Definition:** High-level financial Key Performance Indicators (KPIs) for an organization's reporting period, specifically total revenue and year-over-year growth percentage.
- **What It Is NOT:** Not the complete granular `Report Data`; a concise executive summary payload.
- **Rejected Synonyms (Do Not Use):** `KPI Summary`, `Revenue Overview`, `Executive Brief`
- **Canonical Type / Schema:** `src/data-api/report-summary-schema.ts :: reportSummarySchema`

---

## TMA Breakdown Data

- **Definition:** Categorical market analysis data providing categorical segment titles, single-dimension values, and corresponding hex color mappings.
- **What It Is NOT:** Not a timeseries; categorical distribution data paired directly with visual styling.
- **Rejected Synonyms (Do Not Use):** `Pie Data`, `Segment Metrics`, `Category Distribution`
- **Canonical Type / Schema:** `src/data-api/tma-data-schema.ts :: tmaBreakdownDataSchema`

---

## TMA Series Data

- **Definition:** Chronological timeseries metrics anchored to a specific snapshot timestamp (`asOf`) with sequential numeric data points.
- **What It Is NOT:** Not categorical breakdown data; an ordered temporal measurement series.
- **Rejected Synonyms (Do Not Use):** `Timeline Metrics`, `Historical Series`, `Trend Data`
- **Canonical Type / Schema:** `src/data-api/tma-data-schema.ts :: tmaSeriesDataSchema`
